⚙️ Ajustes de conexión

Conectá la app con Google Sheets para sincronización en tiempo real

🔗 Google Sheets API

Pegá acá la URL del Apps Script que publicaste como Web App. Todos los cambios se sincronizarán automáticamente con tu Google Sheet.

📤 Cargar clientes al Sheets

La primera vez que conectés, usá este botón para subir todos los clientes actuales de la app hacia Google Sheets. Solo es necesario hacerlo una vez.

📋 Instrucciones rápidas
  1. Abrí tu Google Sheet → Extensiones → Apps Script
  2. Borrá todo el contenido y pegá el script que te di
  3. Ejecutá la función setup() (solo una vez)
  4. Publicá: Implementar → Nueva implementación → Web App
  5. En "Ejecutar como": Yo · En "Quién puede acceder": Cualquiera
  6. Copiá la URL y pegala arriba
